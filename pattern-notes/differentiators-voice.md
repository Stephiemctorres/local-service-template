# Pattern Note: Differentiators & Voice — Worked Example, Not a Script

## What this is for
The generic `src/_data/differentiators.js` slots and the About section's
free-text sentence in `index.html` are intentionally left as brackets, not
filled with default prose — because the right *voice* for a business is a
judgment call the client (or whoever's writing their copy) has to make, not
something a template should decide for them.

This note exists so that judgment call isn't made blind. It's a **worked
example** of one real business's voice choice, kept as documentation so a
future build can see what "warm and personal" actually looked like in
practice — without every future client inheriting that exact business's
words.

## The original line, as a reference
The COLD Community NEMT build used this in its About section:

> "We treat every client like family, because that's exactly how we run
> things. When you ride with us, your loved ones are in trusted hands."

Worth noticing what makes this work *for that business specifically*:
- It's grounded in something true about the business (family-owned, two
  named owners who personally do the work) — the sentence earns the word
  "family" rather than using it as generic warmth.
- It speaks to the actual emotional stakes of the service (a loved one's
  safety), which is real and specific to medical transport.

## Why this doesn't become default template copy
Both of the things that make the line work — the family-ownership fact,
and the emotional stakes being about a "loved one's" safety — are specific
to this business and this industry. Reusing the sentence shape for a
coaching business or an irrigation company would produce something that
sounds warm without being true, which reads as worse than no warmth at all.

## How to use this for the pipeline's actual clients
Write the equivalent sentence from scratch for each business, using the
same *approach* — find the thing that's actually true about this specific
business, and let the warmth come from specificity rather than a generic
"like family" phrase:

- **Booster club:** something true about volunteers/parents showing up
  for kids, if that's genuinely the club's character.
- **Pet-inspection business:** something true about care/thoroughness with
  someone's pet, if that's the actual differentiator, rather than
  borrowing "like family" wholesale.
- **Coaching business:** something true about the coach's own approach or
  philosophy, not a generic "we care about your success" line.
- **Irrigation company:** likely a more plainly practical voice is
  correct here — forcing warmth onto a technical service can read as
  insincere. Not every business needs this kind of line at all.

The differentiator cards in `src/_data/differentiators.js` work the same
way: "Family-Operated" was one true, specific differentiator for one
business. A future client's actual differentiators need to be found the
same way — asking what's actually true and distinctive about *this*
business — not generated by filling in a template shape.
